# 飞檐翚影 —— 中国古建筑文化展示平台

## 一、项目简介

“飞檐翚影”是一个面向中国古建筑文化传播的数字化展示平台。项目以中国古建筑为核心内容，结合数据可视化、知识展示、3D 展示、AI 助手和后台管理等功能，构建了一个集文化科普、交互浏览、数据管理和沉浸式体验于一体的综合性 Web 平台。

平台主要展示古建筑的地域分布、历史演化、建筑类型、民族特色、建筑元素、文献资料和三维展馆内容，适用于比赛展示、课程设计、数字文旅项目和传统文化传播场景。

## 二、项目特色

- 中国古建筑主题展示，具有传统文化传播价值
- 前台展示、后端接口、后台管理三端结构完整
- 支持空间分布、时间演化、3D 展示、AI 助手等多个模块
- 集成 ECharts、D3.js、Three.js 等可视化与三维交互技术
- 提供古建筑数据、朝代数据、地域数据、建筑元素和文献资料管理
- 支持沉浸式 3D 数字展馆浏览体验

## 三、功能模块

### 1. 首页展示

展示平台主题、项目入口和整体视觉风格，作为系统的统一入口页面。

### 2. 空间漫游

基于古建筑地域数据和经纬度信息，展示中国古建筑的空间分布情况。

### 3. 民族之窗

围绕不同地域、民族文化和建筑特色进行展示，体现古建筑背后的文化差异。

### 4. 时间之境

按照朝代和历史时期展示古建筑的发展脉络，体现中国古建筑的时间演化过程。

### 5. 3D 展示

通过三维模型或三维视觉效果展示典型古建筑，增强用户的空间感和沉浸感。

### 6. 喜好映射

根据用户偏好或建筑特征进行推荐展示，提升平台的个性化体验。

### 7. AI 助手

提供古建筑知识问答功能，用户可以围绕建筑名称、朝代、结构、屋顶、斗拱等内容进行提问。

### 8. 3D 展厅

基于 Three.js 数字展馆效果，构建沉浸式古建筑展厅，支持用户在虚拟空间中浏览古建筑内容。

### 9. 后台管理

基于 Vue 3 + Element Plus 实现古建筑、朝代、地域、建筑元素、文献资料等数据的管理维护。
